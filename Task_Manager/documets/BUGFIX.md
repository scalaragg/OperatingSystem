# BUGFIX — задачи и исправления

В этом файле записываются обнаруженные ошибки, их причина и способ исправления.
Исправления, выполненные в рабочей копии, отмечаются как исправленные. Функции, которые ещё не реализованы, перечислены отдельно.

## 1. Ошибки консольной версии

### BUG-001 — Не проверялся номер выбранной задачи
- **Проблема:** пользователь мог ввести номер, которого нет в списке.
- **Причина:** перед обращением к элементу списка требовалась проверка диапазона.
- **Исправление:** добавлена проверка номера через вспомогательную функцию `check_confirm`.
- **Статус:** исправлено.

### BUG-002 — Пустые название или описание задачи
- **Проблема:** можно было создать задачу без названия или содержимого.
- **Исправление:** значения очищаются от пробелов и проверяются перед добавлением или редактированием.
- **Статус:** исправлено в консольной логике.

### BUG-003 — Файл сохранения отсутствует при первом запуске
- **Проблема:** при первом запуске файл с задачами мог отсутствовать.
- **Исправление:** добавлена проверка/создание файла перед загрузкой; загрузка возвращает пустой список, если файла нет.
- **Статус:** исправлено.

## 2. Ошибки хранения данных и структуры модулей

### BUG-004 — Синтаксическая ошибка в `storage.py`
- **Проблема:** незаконченная конструкция `if not` не позволяла импортировать модуль.
- **Исправление:** некорректный фрагмент загрузки удалён; функции загрузки и сохранения приведены к согласованному текстовому формату.
- **Статус:** исправлено в рабочей копии.

### BUG-005 — Отсутствовала функция `save_tasks`
- **Проблема:** `app.py` импортировал и вызывал функцию сохранения, которой не было в `storage.py`.
- **Исправление:** добавлена функция `save_tasks(task_list, name_file)`, записывающая задачи построчно.
- **Статус:** исправлено в рабочей копии.

### BUG-006 — Формат файла не соответствовал расширению JSON
- **Проблема:** файл `saves.json` содержал строки вида `название | описание`, а не JSON-структуру.
- **Исправление:** реализовано чтение JSON и автоматическое преобразование старых строк в объекты с полями `title`, `description`, `completed`. Перед преобразованием создаётся резервная копия `saves.json.bak`.
- **Статус:** исправлено; миграция включена в `storage.py`.

### BUG-007 — Несогласованные импорты модулей интерфейса
- **Проблема:** `interface.py` импортировал `Button` и `Frame` как модули верхнего уровня, хотя файлы находятся внутри пакета `ui`.
- **Исправление:** импорты соседних модулей заменены на относительные: `from .AppButton import AppButton` и `from .Frame import AppFrame`.
- **Статус:** исправлено.

### BUG-008 — Ошибка запуска `main.py` из PyCharm
- **Проблема:** относительный импорт `from .ui.interface import Interface` не работал при запуске файла напрямую кнопкой Run.
- **Исправление:** для используемой конфигурации PyCharm применяется `from ui.interface import Interface` при рабочем каталоге `src`.
- **Статус:** исправлено; запуск проверен пользователем в PyCharm.

### BUG-009 — Побочные действия при импорте `view.py`
- **Проблема:** создание окна и вызов функций происходили на уровне модуля, то есть при одном только импорте.
- **Исправление:** запуск интерфейса перенесён в точку входа; модуль представления не должен самостоятельно запускать главный цикл Tkinter.
- **Статус:** исправлено в рабочей копии.

## 3. Ошибки Tkinter-интерфейса

### BUG-010 — Неверные аргументы при создании кнопки
- **Проблема:** в `interface.py` передавался аргумент `color`, которого нет в конструкторе `AppButton`.
- **Исправление:** вызов приведён к параметрам конструктора класса кнопки.
- **Статус:** исправлено.

### BUG-011 — Метод очистки списка был вложен в другой метод
- **Проблема:** `delete_list` был объявлен внутри `add_to_list` и поэтому не являлся методом экземпляра `Listbox`.
- **Исправление:** метод перенесён на уровень класса.
- **Статус:** исправлено.

### BUG-012 — Дублирование класса `AppButton`
- **Проблема:** класс кнопки был объявлен и в `Button.py`, и в `Frame.py`.
- **Исправление:** оставлен один класс `AppButton` в отдельном модуле `AppButton.py`.
- **Статус:** исправлено в рабочей копии.

### BUG-013 — Перекрытие экранов и управление отображением Frame
- **Проблема:** экраны создавались и упаковывались одновременно, из-за чего могли перекрывать друг друга.
- **Исправление:** добавлено явное скрытие и отображение экранов через `pack_forget` и `pack`.
- **Статус:** исправлено в рабочей копии.

### BUG-014 — Ненадёжный путь к иконке окна
- **Проблема:** относительный путь к `icon.ico` зависел от текущей рабочей директории.
- **Исправление:** путь формируется относительно расположения проекта; отсутствие иконки не должно останавливать запуск.
- **Статус:** исправлено в рабочей копии.

## 5. Исправления и улучшения текущего этапа

### BUG-015 — Список задач не имел отдельного компонента приложения
- **Проблема:** отображение списка было связано с базовым Tkinter Listbox и не имело отдельного интерфейса методов.
- **Исправление:** создан `AppListbox.py` с методами `add_to_list`, `delete_list` и `show_tasks`.
- **Статус:** исправлено.

### BUG-016 — Отсутствовал единый компонент для текстовых подписей
- **Проблема:** заголовки и поясняющие надписи создавались напрямую через `tk.Label`.
- **Исправление:** создан класс `AppLabel` в `AppLabel.py`; он используется на экранах меню и списка задач.
- **Статус:** исправлено.

### BUG-017 — Имя файла интерфейса не соответствовало требуемой структуре
- **Проблема:** основная реализация находилась в `interface.py`, тогда как в задании указан `Interface.py`.
- **Исправление:** основная реализация перенесена в `Interface.py`; старый `interface.py` оставлен как модуль совместимости.
- **Статус:** исправлено.

### BUG-018 — Имя файла кнопки не соответствовало требуемой структуре
- **Проблема:** класс находился в `Button.py`, тогда как в задании указан `AppButton.py`.
- **Исправление:** создан `AppButton.py`; `Button.py` оставлен как модуль совместимости.
- **Статус:** исправлено.

### BUG-019 — Старые данные могли потеряться при переходе на JSON
- **Проблема:** прежний файл `saves.json` фактически содержал строки TXT-формата.
- **Исправление:** добавлено распознавание старого формата, преобразование строк в JSON-объекты и создание резервной копии `.bak`.
- **Статус:** исправлено; требуется проверить миграцию на локальной копии пользовательских данных.
