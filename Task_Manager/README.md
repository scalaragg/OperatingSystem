# Task Manager

Учебный проект менеджера задач на Python с графическим интерфейсом Tkinter.

## Запуск

Откройте `src/main.py` в PyCharm и нажмите **Run**. Для этой конфигурации рабочим каталогом должен быть `src`, как в текущей настройке проекта.

## Возможности текущего этапа

- Главное окно Tkinter и переход между экранами.
- Отображение списка задач с помощью собственного класса `AppListbox`.
- Переиспользуемые компоненты `AppButton` и `AppLabel`.
- Хранение задач в JSON-файле `saves.json`.
- Автоматическая миграция старого построчного формата в JSON.
- Создание резервной копии старого файла при миграции (`saves.json.bak`).

## Структура

- `src/main.py` — точка входа.
- `src/ui/Interface.py` — главное окно приложения.
- `src/ui/AppButton.py` — класс кнопки.
- `src/ui/AppLabel.py` — класс текстовой метки.
- `src/ui/AppListbox.py` — класс списка задач.
- `src/storage.py` — загрузка, миграция и сохранение JSON.
- `src/view.py` — отображение задач.
- `src/config.py` — настройки и путь к файлу данных.
- `docs/` — документация проекта.

Файлы `ui/interface.py`, `ui/Button.py` и `ui/Listbox.py` сохранены как небольшие модули совместимости со старыми импортами.

## Формат JSON

Каждая задача хранится как объект с полями `title`, `description` и `completed`.
